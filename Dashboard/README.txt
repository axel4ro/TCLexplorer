LANDER DASHBOARD - PACHET DE DISTRIBUTIE

Continut:
- dashboard.html - aplicatia
- assets/css - stilurile
- assets/js - logica dashboard-ului si integrarea MultiversX
- START-DASHBOARD.bat - pornire locala rapida pe Windows

Pornire pe Windows:
1. Dezarhiveaza/pastreaza intregul folder.
2. Ruleaza START-DASHBOARD.bat.
3. Deschide in browser:
   http://127.0.0.1:8080/dashboard.html

Alternativ, din terminalul deschis in acest folder:
   python -m http.server 8080

Aplicatia necesita acces la internet pentru datele live de la API-ul public MultiversX.
Nu muta dashboard.html separat de folderul assets.
